# Scientific-calculator
Scientific calculator built with HTML, CSS and JavaScript

About the Project

The Scientific Calculator is a web-based application designed to perform basic arithmetic operations and advanced scientific calculations through a simple and user-friendly interface.

Technologies Used

- HTML5
- CSS3
- JavaScript

Main Features

- Addition, subtraction, multiplication, and division
- Trigonometric functions (sin, cos, tan)
- Square and square root calculations
- Percentage calculations
- Logarithmic functions
- Exponential calculations
- Clear and delete functionality
- Responsive user interface
- Real-time calculation results

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your web browser.
